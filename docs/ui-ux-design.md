# siyuan-paper-manager UI/UX 设计

> **实现状态（0.4.0）**：本文已对照 `src/` 当前实现修订。命令、顶栏、五组 Tab 设置、导入/查重合并/引用导出对话框和论文页右键菜单均已实现。具体操作见项目 README。

> 本设计面向用户可感知的界面与交互。所有界面均基于思源插件 API（`Setting`/`Dialog`/`Menu`/`addCommand`/`addTopBar`/`addStatusBar`）实现，均为思源原生支持的交互形式，不引入自定义复杂框架。
> 与功能设计对应：`../docs/implementation-design.md`。

## 一、设计原则

1. **少侵入、贴近思源习惯**：优先复用思源原生交互（命令面板、右键菜单、块属性、原生数据库），不另起一套与思源割裂的界面。
2. **一个入口一个动作**：所有一次性动作（导入本地 PDF、翻译、编辑元数据）都从明确入口触发，避免用户找不到。
3. **设置分组清晰**：设置面板按功能分组（Tab），避免长表单铺满一屏。
4. **长任务有反馈**：翻译是长耗时任务，必须有进度与完成/失败通知。
5. **中文为主**：界面文案中文优先，i18n 预留。

## 二、命令面板（addCommand）

注册的全局命令自动进入思源命令面板（`Cmd/Ctrl+P`），配置快捷键。

| 命令 | 说明 | 快捷键 | 触发动作 |
|---|---|---|---|
| `import-local-pdf` | 导入本地 PDF | `⌥I` | 打开"导入 PDF"对话框 |
| `refresh-paper-meta` | 刷新当前论文元数据摘要 | `⌥E` | 以数据库行为权威重建元数据摘要区 |
| `translate-current-paper` | 翻译当前论文 | `⌥T` | 调用 pdf2zh 翻译当前文档 |
| `export-library-citations` | 导出文献库引用 | — | 打开引用导出对话框（预选当前库） |
| `paper-manager-status` | 环境自检 | — | 对话框展示 Node、Connector、pdf2zh、模板环境 |

> 命令面板是主入口。其余界面（右键菜单、顶栏和文献库数据库）为快捷入口。
> 元数据的编辑不再走独立对话框：用户直接在文献库数据库行中编辑，摘要用上面的刷新命令重建（见第六节）。

## 三、顶栏与文献库

### 3.1 顶栏图标（addTopBar）
- 图标 `iconFiles`，标题"论文管理"，位于顶栏右侧。点击弹出**快速菜单**：
  - 导入本地 PDF
  - 翻译当前论文
  - 刷新当前论文元数据摘要
  - 导出文献库引用
  - 启动/停止 Zotero 接收（图标随 Connector 状态切换）
  - 环境自检
  - 插件设置
- 菜单按按钮边界定位（右边缘对齐），避免贴近视口右缘时错位。

### 3.2 状态栏（addStatusBar）
- 左下角翻译进度胶囊：标签 + 细进度条，进度来自 pdf2zh 输出解析；多篇排队时显示当前进度与队列长度。
- 成功 5 秒、失败 12 秒后自动隐藏。

### 3.3 文献库数据库

文献库文档内嵌原生数据库。**数据库行是用户可见元数据的权威**：用户在数据库中直接编辑元数据；论文页的元数据摘要区由「刷新元数据摘要」以数据库内容重建。数据库行缺失或结构损坏时，可通过设置中的「重新同步 / 修复数据库」恢复。

## 四、设置面板（Setting，分组 Tab）

设置面板用单个自定义表单实现顶部 Tab 切换（820×680），点「确认」统一保存。分 5 个 Tab：

### Tab 1：文献库

默认库下拉切换、新建文献库（打开向导）、项目定义编辑（名称 + 可搜索绑定思源项目文档）、「重新同步」「修复数据库」按钮。

### Tab 2：导入与接收

| 表单项 | 控件 | 说明 | 默认 |
|---|---|---|---|
| Zotero 端口 | 数字输入 | 监听端口（1024–65535） | `23119` |
| 启动时自动监听 | 开关 | onload 是否自动启动 Connector | 开启 |

> Connector 与本地 PDF 始终导入默认文献库，不再单独配置目标笔记本/存放路径。

### Tab 3：论文存储

| 表单项 | 控件 | 说明 | 默认 |
|---|---|---|---|
| 附件目录 | 文本 | 附件转存目录（`assetsDirPath`） | `/assets/` |

> 元数据模板与笔记模板随插件打包，不写入 `data/templates`，用户不可自定义，因此设置面板不提供模板配置。

### Tab 4：PDF 元数据

| 表单项 | 控件 | 说明 | 默认 |
|---|---|---|---|
| 中文检索（实验性） | 开关 | 是否启用知网中文元数据增强 | 关闭 |

> 提取回退顺序固定为：本地 XMP/文档属性 → DOI/Crossref → Citoid → 中文候选（开关开启时）。

### Tab 5：翻译

| 表单项 | 控件 | 说明 | 默认 |
|---|---|---|---|
| pdf2zh 路径 | 文本 | 本地 pdf2zh 可执行文件/命令 | `pdf2zh` |
| 源语言 / 目标语言 | 文本 | `-li` / `-lo` | `en` / `zh` |
| 翻译服务 | 文本 | `-s`（google/deepl/openai…） | `google` |
| 保留双语版 | 开关 | 是否保留 `-dual.pdf` | 开启 |
| 重新翻译后删除旧版本 | 开关 | 新翻译及元数据保存成功后删除旧翻译资源 | 关闭 |
| 额外 CLI 参数 | 多行文本 | 追加到命令的参数（支持引号） | 空 |
| 翻译资源目录 | 文本 | 翻译 PDF 的 assets 目录 | `/assets/` |

> 表单输入实时写入草稿，`confirmCallback` 里统一 `normalizeSettings` 后 `saveData` 持久化；端口或自动监听变化会重启 Connector。

## 五、导入本地 PDF 对话框（Dialog）

触发：命令 `import-local-pdf` / 顶栏菜单。对话框内容：

- PDF 文件选择（`accept="application/pdf"`）；
- 「自动提取元数据」开关（默认开）；
- 「识别候选」下拉：每个候选显示 来源（xmp/crossref/citoid/cnki/filename）· 标题 · 置信度；
- 预览区：所选候选的来源、置信度、标题、作者、期刊、日期、DOI 与识别理由，以及网络告警；
- 操作：取消 / 导入并创建。

行为：

- 选择文件后 `MetadataExtractor` 提取元数据（XMP → DOI/Crossref → Citoid → 可选中文检索），期间导入按钮禁用；提取失败自动回退到文件名候选，仍允许导入。
- 关闭自动提取时直接使用文件名候选。
- 导入走统一 `ItemProcessor`（上传附件 → 查重 → 建文档 → 绑定数据库），始终进入默认文献库；导入的是当前默认库，因此对话框不再提供笔记本/路径选择。

## 六、元数据编辑：数据库即入口（原"编辑元数据对话框"已取消）

0.4.0 起，**文献库数据库行是用户可见元数据的唯一权威**，不再提供独立的"编辑元数据"对话框：

- 用户在文献库数据库中直接编辑标题、作者、年份、DOI、标签等列；
- 「刷新当前论文元数据摘要」（`⌥E` / 右键菜单）以数据库行重建论文页的元数据摘要区；
- 反向回写（数据库 ← 外部数据）只发生在导入/合并时，插件的日常刷新绝不覆盖用户在数据库中的编辑；
- 查重合并对话框是唯一会改动元数据的弹窗：列出冲突字段，默认只填补空字段，勾选后才用传入值覆盖。

## 七、查重合并对话框（Dialog）

导入检测到重复时（DOI 相同，或 citekey 相同）弹出：

- 顶部说明重复原因（DOI 相同 / citekey 相同但 DOI 或标题疑似冲突 / citekey 与标题相同）；
- 现有与传入论文标题对照；
- 冲突字段复选框列表（现有值 vs 传入值）；
- 操作：取消（放弃导入）/ 新建副本 / 合并（默认只补空字段，勾选的字段强制覆盖）。

## 八、论文元数据页（生成的文档）版式设计

每篇论文生成的思源文档自上而下：

```
┌──────────────────────────────────────┐
│ # 论文标题                            │
├──────────────────────────────────────┤
│ ◆ 元数据区（paper-meta 渲染，自动刷新） │
│   类型 / 作者 / 日期 / 期刊 / 卷期 /    │
│   DOI / 链接 / 摘要 / 附件 / 翻译版本   │
├──────────────────────────────────────┤
│ ◆ 笔记区（paper-note 创建时一次性，     │
│    之后用户自由编辑，不被覆盖）          │
└──────────────────────────────────────┘
```

- 元数据区与笔记区通过块属性 `custom-section = meta / note` 标记（见设计文档 4.8）。
- 文档名即 citekey；首个 H1 是论文标题。文档自定义属性保存机器状态：附件清单、翻译版地址、处理状态、文献库归属，用户无需直接编辑。

## 九、翻译流程交互（用户视角）

触发：命令 `translate-current-paper` / 文档右键 → "翻译本文档"。

```
点击"翻译本文档"
   → 状态栏胶囊展示进度（百分比 + 队列长度）
   → 完成后通知耗时；旧翻译资源按设置自动清理
   → 元数据模板区"翻译版本"区块自动出现两个链接：
        [单语翻译版]  [双语对照版]
```

- 已有翻译版本时先确认：按「重新翻译后删除旧版本」设置说明旧资源去留，用户确认才继续。
- 多篇论文同时触发时排队串行执行，同一篇重复触发会被拒绝。
- 翻译失败（pdf2zh 未安装/模型下载失败/服务不可用）：通知明确原因并提示处理方式（如"请安装 pdf2zh""设置 HF_ENDPOINT 镜像"）。

## 十、右键菜单（编辑器 / 文档树）

通过 `eventBus.on("open-menu-content")` 与 `open-menu-doctree` 追加菜单项。目标文档类型由数据库判定（父文档是文献库且有条目，或全库兜底扫描命中），不看隐藏字段：

| 目标 | 菜单项 | 触发 |
|---|---|---|
| 论文页 | 翻译本文档 | 触发 pdf2zh 翻译 |
| 论文页 | 刷新元数据摘要 | 以数据库行重建摘要区 |
| 文献库页 | 导出文献库引用 | 打开引用导出对话框 |

普通文档不追加任何菜单项，避免污染右键菜单。

## 十一、引用导出对话框（Dialog）

触发：命令 `export-library-citations` / 顶栏菜单 / 文献库页右键。任何文档都能打开，文献库在对话框内选择（当前文档是文献库则预选它，是论文页则预选其所属库）。

- 工具栏：文献库切换、搜索（标题/作者/DOI/citekey）、项目过滤、格式选择；
- 项目链接行：绑定了思源文档的项目可点击跳转；
- 左侧论文列表（默认全选，可搜索过滤后批量选择/清空）；右侧导出预览；
- 格式：GB/T 7714—2015（顺序编码/著者—出版年）、APA 7、IEEE、BibTeX、BibLaTeX、Typst Hayagriva YAML、LaTeX `\cite`/`\parencite`/`\textcite`、Typst `@key`/`#cite`；
- 缺作者/年份/来源时在底部给出提示；结果可复制或下载 `.txt`/`.bib`/`.yaml`。

## 十二、空态与引导

- 首次启用且不存在文献库时打开初始化向导（选择笔记本、名称、路径）；已完成但默认库指针丢失时自动认领第一个库，不再打扰。
- 未完成初始化前，导入命令报错提示先设置默认文献库。
- pdf2zh 未检测到：翻译命令触发时提示"未检测到 pdf2zh，请先安装并在设置中填写可执行路径"。
- 中文检索开关默认关闭，设置页标注"实验性"。

## 十三、与其他能力的衔接

| 设计文档章节 | 对应 UI |
|---|---|
| 能力1 附件保存 | 无独立 UI，后台完成；翻译入口在论文页 |
| 能力2 元数据页 | 第八节版式 + 第六节数据库编辑 |
| 能力3 PDF 导入 | 第五节导入对话框 |
| 能力4 翻译 | 第九节翻译交互 + 设置 Tab5 |
