# siyuan-paper-manager UI/UX 设计

> **实现状态（0.4.0）**：命令、顶栏、五组 Tab 设置、导入/编辑/重复合并对话框和论文页右键菜单已实现。具体操作见项目 README。

> 本设计面向用户可感知的界面与交互。所有界面均基于思源插件 API（`Setting`/`Dialog`/`Menu`/`addCommand`/`addDock`/`addTopBar`/`addStatusBar`）实现，均为思源原生支持的交互形式，不引入自定义复杂框架。
> 与功能设计对应：`../docs/implementation-design.md`。

## 一、设计原则

1. **少侵入、贴近思源习惯**：优先复用思源原生交互（命令面板、右键菜单、块属性、原生数据库），不另起一套与思源割裂的界面。
2. **一个入口一个动作**：所有一次性动作（导入本地 PDF、翻译、编辑元数据）都从明确入口触发，避免用户找不到。
3. **设置分组清晰**：设置面板按功能分组（Tab），避免长表单铺满一屏。
4. **长任务有反馈**：翻译是长耗时任务，必须有进度与完成/失败通知。
5. **中文为主**：界面文案中文优先，i18n 预留。

## 二、命令面板（addCommand）

注册的全局命令自动进入思源命令面板（`Cmd/Ctrl+P`），配置快捷键。

| 命令 | 说明 | 快捷键（建议） | 触发动作 |
|---|---|---|---|
| `import-local-pdf` | 导入本地 PDF | `⌥I` | 打开"导入 PDF"对话框 |
| `edit-paper-metadata` | 编辑当前论文元数据 | `⌥E` | 打开"编辑元数据"对话框（当前文档） |
| `translate-current-paper` | 翻译当前论文 | `⌥T` | 调用 pdf2zh 翻译当前文档 |
| `paper-manager-status` | 环境自检 | — | 对话框展示连接、模板和翻译环境 |

> 命令面板是主入口。其余界面（右键菜单、顶栏和文献库数据库）为快捷入口。

## 三、顶栏与文献库

### 3.1 顶栏图标（addTopBar）
- 一个图标（如 `iconLanguage` 或 `iconFiles`），标题"论文管理"。点击弹出**快速菜单**：
  - 导入本地 PDF
  - 翻译当前论文
  - 打开插件设置
  - 启动/停止 Zotero 接收（开关，反映 Connector 状态）

### 3.2 文献库数据库

文献库文档内嵌原生数据库。论文元数据由插件编辑页写入 base64 后投影到数据库；数据库可通过设置中的“重新同步/修复”重建。

## 四、设置面板（Setting，分组 Tab）

设置面板用 `Setting` 类的 `setTabs`/`addTab` 分组，避免单页超长。分 5 个 Tab：

### Tab 1：文献库

管理默认库、新建库、字段投影、项目映射和数据库同步。

### Tab 2：导入与接收（Import & Receiving）

| 表单项 | 控件 | 说明 | 默认 |
|---|---|---|---|
| Zotero 端口 | `addText`（数字） | 监听端口 | `23119` |
| 启动时自动监听 | `addSwitch` | onload 是否自动启动 Connector | 开启 |
| 目标笔记本 | `addSelect` | 保存文献的笔记本（`/api/notebook/lsNotebooks` 列出） | 用户选择 |
| 存放路径 | `addText`（相对 hpath） | 笔记本内文档树路径 | `/文献库` |

### Tab 2：论文存储（Metadata Page）

| 表单项 | 控件 | 说明 | 默认 |
|---|---|---|---|
| 附件目录 | `addText`（`assetsDirPath`） | 附件转存目录 | `/assets/` |
| 元数据模板 | 只读提示 | 模板随插件打包，无需配置 | 内置 |
| 编辑元数据 UI | `addSwitch` | 是否启用插件自建编辑对话框（隐藏字段唯一入口） | 开启 |

> 模板文件随插件打包（`data/plugins/{插件名}/templates/`），安装/更新/卸载自动管理，用户不可自定义，因此设置面板不提供模板路径配置。

### Tab 3：PDF 元数据（PDF Import）

| 表单项 | 控件 | 说明 | 默认 |
|---|---|---|---|
| 提取回退顺序 | `addSelect` | `XMP → DOI/Citoid → 中文检索` | 默认顺序 |
| 中文检索（知网） | `addSwitch` | 是否启用知网中文元数据增强 | 关闭 |

### Tab 4：翻译（Translation）

| 表单项 | 控件 | 说明 | 默认 |
|---|---|---|---|
| pdf2zh 路径 | `addText` | 本地 pdf2zh 可执行文件/命令 | `pdf2zh` |
| 翻译源语言 | `addText` | `-li` | `en` |
| 目标语言 | `addText` | `-lo` | `zh` |
| 翻译服务 | `addText` | `-s`（google/deepl/openai…） | `google` |
| 额外 CLI 参数 | `addTextarea` | 追加到命令的参数（如 `-t 4`） | 空 |
| 是否生成双语版 | `addSwitch` | 是否保留 `-dual.pdf` | 开启 |
| 翻译输出目录 | `addText` | 生成 mono/dual 的落盘目录 | `/assets/` |

> 设置项均通过 `change` 事件写入 `this.settings`，`confirmCallback` 里 `saveData` 持久化。初始值必须放在 `action` 回调内设置。

## 五、导入本地 PDF 对话框（Dialog）

触发：命令 `import-local-pdf` / 顶栏菜单。一个简洁对话框：

```
┌───────────────────────────────────┐
│  导入本地 PDF                        │
├───────────────────────────────────┤
│  [选择文件…]  xxx.pdf                │
│  自动提取元数据：☑ 是                 │
│  目标笔记本：▼ [已选笔记本]           │
│  存放路径：  [/文献库/论文]           │
│                                     │
│       [取消]      [导入并创建]       │
└───────────────────────────────────┘
```

- 选择文件后，后端 `MetadataExtractor` 提取元数据（XMP→DOI→中文），提取期间按钮显示"提取中…"。
- 提取完成填充元数据预览（标题/作者/期刊），供用户确认。
- 确定后：上传附件 → 渲染模板建文档 → 写隐藏字段 → 显示成功通知。
- 若元数据缺失（如纯扫描 PDF），提示"未能识别，可稍后手动编辑"，仍允许创建。

## 六、编辑元数据对话框（Dialog）

触发：命令 `edit-paper-metadata` / 论文文档右键。这是隐藏字段的**唯一修改入口**。

```
┌──────────────────────────────────────────────┐
│  编辑论文元数据  (citekey: smith2024)          │
├──────────────────────────────────────────────┤
│  标题      [____________________________]     │
│  作者      [____________________________]     │
│  期刊      [____________________________]     │
│  年份      [____________]   DOI [___________] │
│  摘要      [ 多行文本域                       ] │
│  关键词    [tag1, tag2]                       │
│  …(可按需精简/扩展字段)                         │
│  附件 PDF  [assets/xxx.pdf] (只读)             │
│                                               │
│      [取消]      [保存并刷新元数据区]           │
└──────────────────────────────────────────────┘
```

行为：
- 打开时加载 `custom-paper-data`（base64解码）并填充表单。
- 点"保存"：① 更新 `custom-paper-data` JSON（重新 base64）；② 同步索引字段（citekey/doi 等）；③ `updateBlock` 刷新元数据模板区。（见设计文档 4.7(2)）

## 七、论文元数据页（生成的文档）版式设计

每篇论文生成的思源文档自上而下：

```
┌──────────────────────────────────────┐
│ # 论文标题                            │
├──────────────────────────────────────┤
│ ◆ 元数据区（paper-meta 渲染，自动刷新） │
│   类型 / 作者 / 日期 / 期刊 / 卷期 /    │
│   DOI / 链接 / 摘要 / 附件 / 翻译版本   │
├──────────────────────────────────────┤
│ ◆ 笔记区（paper-note 创建时一次性，     │
│    之后用户自由编辑，不被覆盖）          │
└──────────────────────────────────────┘
```

- 元数据区与笔记区通过块属性 `custom-section = meta / note` 标记（见设计文档 4.8）。
- 文档属性区（右侧/块标菜单）显示索引字段：citekey、DOI、翻译版等，用户可直观看到、但不直接编辑（编辑走插件对话框）。

## 八、翻译流程交互（用户视角）

触发：命令 `translate-current-paper` / 文档右键 → "翻译本文档"。

```
点击"翻译本文档"
   → 顶栏菜单与通知展示翻译状态
   → 完成后通知耗时
   → 通知：翻译完成，已生成双语对照版
   → 元数据模板区"翻译版本"区块自动出现两个链接：
        [单语翻译版]  [双语对照版]
```

- 翻译失败（pdf2zh 未安装/模型下载失败/服务不可用）：通知明确原因并提示处理方式（如"请安装 pdf2zh""设置 HF_ENDPOINT 镜像"）。
- 翻译中再次触发时读取任务状态并阻止重复执行。

## 九、右键菜单（块菜单 / 文档菜单）

论文元数据页文档的右键菜单追加项：

| 菜单项 | 触发 |
|---|---|
| 编辑论文元数据 | 打开编辑对话框 |
| 翻译本文档 | 触发 pdf2zh 翻译 |
| 重新提取元数据 | 重新走 MetadataExtractor（更新字段+模板） |

通过 `eventBus.on("open-menu"...)` 判断目标文档是否带 `custom-paper-data` 字段（是论文页才显示），避免污染普通文档右键菜单。

## 十、空态与引导

- 首次启用且不存在文献库时打开初始化向导；未完成前导入入口提示先设置默认文献库。
- pdf2zh 未检测到：翻译命令触发时提示"未检测到 pdf2zh，请按 README 安装"，并给出安装命令示例。
- 中文检索开关默认关闭，设置页 Tab3 注明"开启后有反爬风险"。

## 十一、与其他能力的衔接

| 设计文档章节 | 对应 UI |
|---|---|
| 能力1 附件保存 | 无独立 UI，后台完成；翻译入口在元数据页 |
| 能力2 元数据页 | 第七节版式 + 第六节编辑对话框 |
| 能力3 PDF 导入 | 第五节导入对话框 |
| 能力4 翻译 | 第八节翻译交互 + 设置 Tab4 |
